# Free Rugby Live

Free Rugby Live helps rugby fans discover free, official broadcasts, upcoming fixtures, competitions, and rugby news in one place.

## Features

- Browse live and upcoming rugby matches
- Filter matches by competition
- Search teams and competitions
- Save matches for later
- Explore URC, Top 14, Super Rugby, Women's Rugby, and Test rugby
- Read rugby news, analysis, and press-room updates
- Open official broadcaster websites
- Client-side login and sponsorship enquiry interface

## Competitions

- United Rugby Championship
- Top 14
- Super Rugby Pacific
- Women's Rugby
- International Tests

## Technology

- HTML
- CSS
- Vanilla JavaScript
- Google Fonts
- Local browser storage for account preferences

## Important Note

Free Rugby Live does not host unauthorized streams. It directs users to official broadcasters and licensed rugby coverage. Broadcast availability may vary by country and region.

## Running Locally

Open `index.html` in a web browser, or serve the folder with any static web server.

## Deployment

This project can be hosted using GitHub Pages, Netlify, Vercel, or any other static hosting provider.
